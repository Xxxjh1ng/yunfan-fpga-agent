# 基准设计集（Benchmark Suite）

| 设计 | 端口数 | 参数 | 说明 |
| --- | --- | --- | --- |
| counter | 6 | 0 | 4 位可加载使能计数器：load 优先于 en，异步低有效复位后输出 0；计满后 |
| pwm | 4 | 0 | 8 位 PWM 发生器：自由运行计数器与占空比比较，输出无毛刺的组合比较结果。 |
| crc32 | 5 | 0 | CRC-32 字节并行校验：多项式 0x04C11DB7，MSB 先行，输入输出 |
| uart_tx | 6 | 1 | UART 8N1 发送器：1 起始位 + 8 数据位（LSB 先行）+ 1 停止 |
| vga_timing | 7 | 8 | 640x480@60 VGA 行场时序发生器：行 800 像素、场 525 行， |
